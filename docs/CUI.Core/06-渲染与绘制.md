# 06 · 渲染与绘制

## 一、绘制契约

```
Render(ctx)                 // ← 基类实现：Opacity / Clip / 层缓存，一般别重写
  ├─ OnRender(ctx)          // ← 你重写这个（UIElement.h:725）
  ├─ 递归 GetVisualChildren() 的 Render(ctx)
  └─ RenderOverlay(ctx)     // 浮层/弹出内容
       └─ OnRenderOverlay(ctx)   // ← 弹出类控件重写（UIElement.h:731）
```

- **所有绘制都写在 `OnRender(GraphicsContext&)` 里**，单位 DIP。
- 绘制前先做脏区裁剪：`if (!ctx.IntersectsPaintBounds(bounds)) return;`
- 坐标取自 `GetBounds()`（布局后的矩形，**已扣 Margin**）。
- 需要画在子树之上 → 用 `RenderOverlay` / `OnRenderOverlay`；并按需重写 `NeedsOverlayHitTest()` / `OnHitTestOverlay()` 让浮层能接收鼠标。

## 二、`GraphicsContext` API（`render/GraphicsContext.h`）

### 帧边界与设备

| API | 说明 |
|---|---|
| `void BeginDraw()` / `HRESULT EndDraw()` | 帧开始 / 结束并提交 |
| `HRESULT EndDraw(const RECT* dirtyRectPx)` | 部分呈现（FLIP_SEQUENTIAL）；`nullptr` = 全量。**物理像素** |
| `void Resize(UINT w, UINT h)` | 交换链缓冲区尺寸，**物理像素** |
| `void SetRequirePerPixelAlpha(bool)` | 逐像素 Alpha 开关 |
| `ID2D1DeviceContext* GetD2DContext()` | 拿原生 D2D 上下文（画框架没封装的东西） |
| `float GetDpiScale()` | 当前 DPI 缩放 |

### 裁剪 / 变换 / 透明度栈（成对使用）

`PushClip(rect)` / `PushRoundedClip(rect, radius)` / `PushEllipseClip(center, rx, ry)` / `PopClip()`
`PushOpacity(float)` / `PopOpacity()`
`PushTransform(const D2D1_MATRIX_3X2_F&)` / `PopTransform()`
`PushPopupReveal(bounds, progress, origin)` / `PopPopupReveal()`
`PushInheritedTextStyle(style)` / `PopInheritedTextStyle()`

> 每次 Push 必须配对 Pop，否则状态栈泄漏、后续全屏绘制异常。

### 文本

## 三、脏区与重绘

| 你改了什么 | 调哪个 |
|---|---|
| 外观整体变了 | `MarkRenderContentDirty()` |
| 只变了一小块 | `MarkRenderRectDirty(rect)` |
| 有动画在跑 | 框架通过 `CollectAnimationBounds()` / `CollectSelfAnimationBounds()` 自动收集脏矩形（可重写） |
| 想接管脏区收集 | `CollectRenderDirtyRegion(DirtyRegion&, bool consume = true)` |

绘制完成后由 `EndDraw(dirtyRectPx)` 做**部分呈现**，所以只标脏小矩形能显著降低 GPU 开销。

## 四、主题取色（绘制路径用枚举，别用字符串）

`ThemeManager::Instance().GetColor(ThemeTokenId)`（`style/ThemeTokenId.h` 共 17 个）：

| Token | 用途 |
|---|---|
| `WindowBackground` | 窗口底色 |
| `CardBackground` / `CardBorder` | 卡片及其描边 |
| `TextPrimary` / `TextSecondary` / `TextMuted` | 三级文本 |
| `AccentColor` / `AccentForeground` | 主色与其上的文字 |
| `DangerColor` | 危险/错误 |
| `PaneBackground` | 侧边栏 |
| `InputBackground` / `InputBorder` | 输入控件 |
| `HoverBackground` / `PressedBackground` / `SelectedBackground` | 交互态 |
| `FocusedBorder` | 焦点边框 |
| `Unset` | 未设置（`Count` 为总数哨兵） |

字符串 ↔ 枚举：`ThemeTokenIdToName(id)` / `ThemeTokenIdFromName(name)`（样式表用）。
主题切换后框架会调用 `OnThemeChanged()`（可重写做自定义处理）。

## 五、常见绘制问题

| 现象 | 排查 |
|---|---|
| 改了数据画面不变 | 忘了 `MarkRenderContentDirty()` / `InvalidateMeasure()` |
| 内容画到控件外面 | 父级没裁剪；检查 `ShouldClipToBounds()` / `SetClipToBounds(true)` |
| Push/Pop 不配对 | 后续绘制全部错位或消失 |
| 高分屏发虚 | 用了物理像素线宽；确保线宽/坐标是 DIP，且 `GetDpiScale()` 已生效 |
| 闪烁 | 没用双缓冲/层缓存，或每帧全量 `EndDraw()`；改成脏矩形呈现 |
| 文字模糊 | 字号/坐标非整数 DIP 且未对齐；或重复创建 TextLayout（改用 `TextLayoutCache`） |
