# 08 · 窗口、输入与弹出层

## 一、Window（`framework/window/Window.h`）

### Fluent 建窗（`Window.h:42` 的 `FluentBuilder`）

```cpp
Window w;
w.Fluent()
   .Title("标题")                 // std::string（UTF-8，内部转 UTF-16）
   .Size(1280, 800)              // 默认 1280×800，DIP
   .MinimumSize(800, 600)
   .Transparent(false)           // 全透明 Alpha 混合模式
   .Theme(ThemeMode::Dark)       // 默认 Dark
   .Backdrop(BackdropType::None) // Mica / Acrylic / None
   .RenderStats(false)
   .Root(root)                   // 等价 SetRootElement
   .Build()                      // 内部 Create()；返回 *this
   .Show()
   .Run();                       // 内部 RunMessageLoop()
```

其它：`Apply()`（对已创建窗口再改设置）、`operator bool()` / `Built()`。

### 命令式 API

```cpp
static Window* Current();                    // 当前窗口（消息泵里维护）
bool Create(title, w = 1280, h = 800, transparentMode = false);
void Show(); void Hide(); void Close();
void RunMessageLoop();
void SetRootElement(std::shared_ptr<UIElement> root);
void SetMinimumSize(int w, int h);
void SetThemeMode(ThemeMode);   void SetBackdropType(BackdropType);
```

属性代理（可直接赋值）：

```cpp
w.ThemeMode   = ThemeMode::Light;       // WindowThemeModeProperty
w.BackdropType = BackdropType::Mica;    // WindowBackdropTypeProperty
w.RenderStats  = true;                  // WindowRenderStatsProperty
```

### CUIWindow（自带标题栏）

`window/CUIWindow.h`：构造时已用 DSL 搭好 `StackPanel(TitleBar + contentContainer)`。

```cpp
CUIWindow app;                    // 默认 1200×750
app.Content(myRoot).Show().Run(); // 内部会先 ClearChildren()
```

## 二、消息泵做的事（`Window::RunMessageLoop`）

1. `PeekMessage` 排空输入类消息（预算 100 条）；`WM_MOUSEMOVE` 只保留最新一条
2. 逐条派发：`UIElement::OnRoutedEvent(RoutedEventArgs&)`（隧穿 + 冒泡）或经典虚函数
3. 取一条普通消息（`WM_QUIT` → 返回）
4. 设置每窗口上下文：`Window::s_current` / `AnimationManager` / `FrameScheduler` / `PopupHost` / `DragDropService`
5. `AnimationService::Instance().Tick(now)`
6. `PumpFrameStep(now)`：Measure → Arrange → SyncRenderState → Render
7. `EndDraw(dirtyRectPx?)` / `CommitComposition()`

## 三、输入：重写哪些虚函数（`UIElement.h:751`+）

```cpp
virtual void OnMouseEnter();
virtual void OnMouseLeave();
virtual void OnMouseDown(Point pt);
virtual void OnMouseUp(Point pt);
virtual void OnMouseMove(Point pt);
virtual void OnMouseDblClick(Point pt);
virtual void OnMouseRightClick(Point pt);
virtual bool OnContextMenuRelease(Point pt);      // 返回 true 拦截
virtual void OnMouseWheel(float delta);
virtual bool OnMiddleButtonDown(Point pt);        // 返回 true 捕获中键滚屏
virtual void OnMiddleButtonUp(Point pt);
virtual bool IsMiddleScrollActive() const;
virtual bool OnKeyDown(int vkCode);               // 返回 true = 完全消费
virtual void OnCharInput(wchar_t ch);             // IME 后的 Unicode 字符
virtual bool AcceptsTabFocus() const;             // 是否可 Tab 聚焦
virtual bool ReceivesTabInput() const;            // Tab 是否当内容输入
virtual void OnAutoScrollTick();
virtual bool NeedsAutoScrollTick() const;
virtual void OnFocus();
virtual void OnBlur();
virtual void OnRoutedEvent(RoutedEventArgs& args); // 路由事件主通道
virtual UIElement* HitTest(float x, float y);      // 命中测试
virtual bool NeedsOverlayHitTest() const;
virtual UIElement* OnHitTestOverlay(float x, float y);
virtual bool UsesZIndexOrdering() const;           // Canvas 覆写为 true
```

**坐标单位**：`Point` 是 DIP。Win32 消息给的是物理像素 → 先 `ClientPhysicalToLogical()` 转换再做命中测试。

**中键自动滚屏**：重写 `OnMiddleButtonDown` 返回 `true` + `IsMiddleScrollActive()` + `NeedsAutoScrollTick()`，在 `OnAutoScrollTick()` 里推进滚动。

## 四、命令与快捷键（`framework/input/`）

- `Command.h` / `Command.cpp`：命令对象（可执行、可绑定快捷键）

## 六、弹出层

| 类型 | 说明 |
|---|---|
| `IPopup` 接口 | `ComboBox`、`ColorPicker`、`DatePicker`、`TimePicker`、`FilePicker`、`FolderPicker`、`AutoSuggestBox`、`DropDownButton`、`ContextMenu`、`Flyout` 都实现它 |
| `PopupHost` | 每窗口的弹出层宿主（`Window::GetPopupHost()`），负责定位与层级 |
| `PopupPlacement` | 放置策略（相对锚点、翻转、屏幕边界回退） |
| `MenuPopupWindow` | 菜单类弹出用独立 HWND（可超出主窗口边界） |
| `ContentDialog` / `MessageBox` | 模态对话框 |
| `TeachingTip` / `Toast` / `ToastCenter` | 气泡提示 / 通知 |

命中测试：弹出内容画在 `RenderOverlay` / `OnRenderOverlay`，并重写 `NeedsOverlayHitTest()` 返回 `true` + `OnHitTestOverlay()` 才能让浮层接收鼠标。

## 七、DPI

- `window/Dpi.h`：物理像素 ↔ DIP 换算（`ClientPhysicalToLogical` 等）
- 窗口创建后按 `GetDpiForWindow(hwnd)` 设置 `m_dpiScale = dpi / 96.0f`，并 `d2dContext->SetDpi()`
- 收到 DPI 变化 → 重建交换链 / 文本布局缓存，并 `InvalidateMeasure()`
- 全屏坐标（`Window` 的 Size、Win32 消息）与逻辑坐标（布局/绘制）不要混用

## 八、窗口背景材质

`WindowBackdrop.h`：`BackdropType::None / Mica / Acrylic`。透明模式需 `Create(..., transparentMode = true)` 并开启逐像素 Alpha（`GraphicsContext::SetRequirePerPixelAlpha(true)`）。
