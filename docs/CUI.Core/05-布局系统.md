# 05 · 布局系统

## 一、两阶段契约（所有布局都遵守）

```
Measure(availableSize)                 // UIElement.h:707，非虚入口，别重写
  ├─ 扣掉 Margin / Padding
  ├─ Panel::MeasureOverride(available) // ← 容器重写这个（Panel.h:18）
  │     子类必须对每个参与布局的子节点调用 child->Measure(约束)
  └─ 记录 DesiredSize

Arrange(finalRect)                     // UIElement.h:713，非虚入口
  ├─ 扣掉 Margin，按 Alignment 决定是否拉伸
  ├─ Panel::ArrangeOverride(finalRect) // ← 容器重写这个（Panel.h:19）
  │     子类必须对每个参与布局的子节点调用 child->Arrange(矩形)
  └─ 写入 m_bounds（GetBounds() 读它）
```

**重写规则**：

- 想改"自己想要多大" → 重写 `MeasureOverride(Size) -> Size`
- 想改"子项放在哪" → 重写 `ArrangeOverride(Rect)`
- 只在 `Panel`（或其子类）里有这两个重写点；普通 `Control` 一般只用 `Width/Height` + `Alignment`
- ⚠️ 必须在 `MeasureOverride` 里对每个子节点 `Measure()`，在 `ArrangeOverride` 里对每个子节点 `Arrange()`，否则子节点尺寸/位置永远不更新

## 二、7 种容器（`controls/Panel.h`）

| 类 | DSL | 行为 | 关键附加属性 |
|---|---|---|---|
| `StackPanel` | `Column(gap)` / `Row(gap)` | 沿朝向线性累加 | `Gap`、`Orientation` |
| `Canvas` | `CanvasWidget()` | 子项自测量 + 绝对定位 | `CanvasLeft/Top/Right/Bottom`、`ZIndex` |
| `Grid` | `GridWidget()` | 行列网格 | `GridRow/GridColumn/GridRowSpan/GridColumnSpan` |
| `WrapPanel` | `WrapPanelWidget("Horizontal")` | 流式排布，满则换行/换列 | `Orientation` |
| `DockPanel` | `DockPanelWidget()` | 按 Dock 边依次缩进，最后一项填满 | `Dock` |
| `UniformGrid` | `UniformGridWidget(rows, cols)` | 等分单元格 | `Rows`、`Columns` |
| `ScrollViewer` | `ScrollViewerWidget()` / `SingleChildScrollView()` | 单子项 + 滚动 | `Orientation`、`OverlayScrollbar` |

另有 `Splitter`（`SplitterWidget`）与 `DockManager`（`DockManagerWidget`）用于可拖拽分隔 / 可停靠布局。

## 三、Grid 语法

`GridLength`（`layout/Layout.h:17`）三种单位：

```cpp
enum class GridUnitType { Pixel, Star, Auto };   // Layout.h:11（顺序以源码为准）

GridLength::Pixel(120.0f);   // 固定 120 DIP
GridLength::Star(2.0f);      // 权重 2
GridLength::Auto();          // 由内容决定
GridLength::Parse("2*");     // 字符串解析
```

字符串写法（**DIP / 权重逗号分隔**）：

```cpp
GridWidget()
  .ColumnDefinitions("Auto,*,2*")     // 第 1 列自适应，第 2 列 1 份，第 3 列 2 份
  .RowDefinitions("48,*");

// 子项定位
Text("A").GridRow(0).GridColumn(0);
Text("B").GridColumn(1).GridColumnSpan(2);
```

解析规则（`GridLength::Parse`，`Layout.cpp:31`）：`"auto"`（不区分大小写）→ Auto；以 `*` 结尾 → Star（前置数字为权重，缺省 1）；否则 → Pixel（`atof`）。
设置入口：`Grid::SetColumnDefinitions(const std::string&)`（`Panel.cpp:49`）按逗号切分逐个 `Parse`。

> ⚠️ 星号列"不回缩"是已知问题（`docs/review/07`）：窗口变窄时 `*` 列可能不按预期收缩。排查时先看 `Layout.cpp` 中星号分配段落。

## 四、对齐与拉伸

- `Align(Alignment)` / `AlignHorizontal` / `AlignVertical`
- `Alignment::Stretch` 让元素填满父级给的空间（默认行为受容器影响）
- 尺寸约束：`Width` / `Height` / `MinWidth` / `MinHeight` / `MaxWidth` / `MaxHeight`；`-1` 通常表示"未设置 / 自动"
- `FlexGrow(flex)`：`StackPanel` 方向上的弹性伸展权重；DSL 也有 `Expanded(child, flex)` 包装
- `Margin` / `Padding`：`Thickness`，支持 `Margin(all)` 与 `Margin(l,t,r,b)`

## 五、失效与重排

| 操作 | API | 效果 |
|---|---|---|
| 内容变了（影响尺寸） | `InvalidateMeasure()` | 置 Measure/Arrange 双脏，向上冒泡，自动请求下一帧 |
| 只位置变了 | `InvalidateArrange()` | 只重排 |
| 结构变了（增删子节点） | `NotifyVisualTreeChanged()` | 递增布局代次、失效父链缓存（`AddChild` 内部已调用） |

调试技巧：`UIElement::GetLayoutGeneration()` 返回全局布局代次，可用于确认是否真的重排过。

## 六、常见布局 Bug 定位顺序

1. 父容器给的 `availableSize` 对不对？（在 `MeasureOverride` 打印）
2. 子节点有没有被 `Measure()` / `Arrange()` 到？（漏调 = 尺寸永远 0）
3. `Margin` / `Padding` 是否被扣了两次？（基类 `Measure` 已扣过，子类别再扣）
4. 单位是不是物理像素？（必须 DIP）
5. `Alignment` 是否把期望尺寸覆盖了？（Stretch 会用父级给的空间）
