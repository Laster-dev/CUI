# 04 · 属性与绑定

CUI.Core 有三套并行的属性机制，分别解决不同问题。**先判断你在改哪一套**，再动代码。

| 机制 | 文件 | 用途 | 典型写法 |
|---|---|---|---|
| 强类型 `Property<T>` / `PropertyRef<T,Id>` | `core/Property.h` | 控件对外暴露的常规属性（编译期检查、可绑定） | `btn->Text = "OK";` |
| 回调属性 `CallbackProperty` | `core/Property.h` | 事件槽位（可 `=` 赋值，也可 `.Connect()` 多播） | `btn->OnClick = f;` |
| 反射属性 `PropertyId` + `Value` | `core/PropertyId.h`、`core/Value.h` | 通用/附加属性、样式表、序列化（运行期按 ID 存取） | `elem->SetValue(PropertyId::Opacity, Value(0.5f))` |

## 一、强类型属性 `Property<T>`

```cpp
// core/Property.h:38 —— 值语义的持有者，内部指向 PropertyRef
template<typename T> class Property final {
    T Get() const;
    void Bind(const std::shared_ptr<Observable<T>>& value, BindingMode mode = BindingMode::TwoWay);
    void Bind(const CUI::State<T>& value,                  BindingMode mode = BindingMode::TwoWay);
    void Bind(const std::shared_ptr<Observable<TSource>>& source, Converter, BindingMode mode);
    void Bind(const CUI::State<TSource>& source,           Converter, BindingMode mode);
    void Unbind();
};
```

- 控件成员属性（如 `Text`、`Width`）实际是 `PropertyRef<T, Id>`（绑定到具体实例），`Property<T>` 是它的值语义包装。
- 赋值即触发变更通知并自动失效/重绘（由 `PropertyRef` 的 setter 决定），**不要**在外部缓存 `Get()` 结果后长期持有。
- 线宽、颜色等绘制用属性同样走这套，绘制前读 `Get()` 即可。

## 二、状态与可观察对象

```cpp
// core/State.h
State<int> count{0};
count.Set(1);
int v = count.Get();

// core/Observable.h
auto obs = std::make_shared<Observable<std::string>>();
```

- `State<T>`：轻量值容器，可直接 `Bind` 给属性。
- `Observable<T>`：多订阅源，适合跨控件共享。
- 派生值用 `MakeComputed(fn, state...)`：源变化时自动重算并推送。

## 三、绑定

```cpp
enum class BindingMode { OneWay, TwoWay, OneTime };   // core/Binding.h

label->Text.Bind(count, BindingMode::OneWay);          // 源 → 目标
editor->Text.Bind(textState, BindingMode::TwoWay);     // 双向
label->Text.Bind(count, [](int c) { return std::to_string(c); }, BindingMode::OneWay);  // 带转换器
label->Text.Unbind();
```

**生命周期**：绑定是值语义的，`Property<T>` 内部按需懒创建 `BindableProperty<T>`（`core/BindableProperty.h`）；控件析构时自动 `Unbind()`，不需要手动清理。

**典型坑**：

- 源类型与目标类型不同 → 必须提供转换器，否则编译期就挂（这是好事，别用 `reinterpret` 绕）。
- 双向绑定两个控件同一属性 → 注意回环，必要时用 `OneWay` + 手动回写。

## 四、反射属性 `PropertyId` + `Value`

```cpp
// core/PropertyId.h:7
enum class PropertyId : uint16_t { /* 全框架统一编号 */ };
const char*   PropertyIdToName(PropertyId id);
PropertyId    PropertyIdFromName(const char* name);
PropertyId    PropertyIdFromName(const std::string& name);

// core/Value.h:201 —— 弱类型容器
class Value {
    enum Type { /* 见源码 */ } ;
    Type GetType() const;
    bool        AsBool(bool def = false) const;
    float       AsFloat(float def = 0.0f) const;
    std::string AsString(const std::string& def = "") const;
    D2D1_COLOR_F AsColor(D2D1_COLOR_F def = D2D1::ColorF(D2D1::ColorF::White)) const;
private:
    std::variant<std::monostate, bool, int, float, std::string, D2D1_COLOR_F, Thickness, void*> m_val;
};
```

- 支持的类型就是上面那个 `variant`：`bool / int / float / std::string / D2D1_COLOR_F / Thickness / void*`。
- 需要新增可反射属性 → 在 `PropertyId.h` 的枚举尾部追加，`PropertyId.cpp` 补名字映射（见 [09](./09-扩展指南.md)）。
- 附加属性（如 `Grid.Row`）也走这套：`SetGridRow(int)` / `GetGridRow()` 是它的强类型快捷方式。

## 五、`PropertyDesc`（属性描述表）

`core/PropertyDesc.h` 提供属性的元信息（名称、类型、默认值、分类），用于：

- 样式表（`framework/parser/` 的硬编码样式表按名字/类名匹配）
- 设计器 / 调试面板
- 序列化

> ⚠️ 这里的"名字"是**字符串**，与 `PropertyId` 枚举配套（`PropertyIdFromName`）。改属性名时注意两处同步。

## 六、事件 vs 回调属性

| 想做的事 | 用哪个 |
|---|---|
| 控件暴露一个可多播的事件 | `Event<T>`（`core/Event.h`）：`Connect` 返回 `EventId`，可 `Disconnect` |
| 控件暴露一个"槽位"给外部赋值 | `CallbackProperty`（`core/Property.h`）：`operator=` 或 `.Connect()` |
| 在自定义控件里响应输入 | 重写虚函数 `OnMouseDown` / `OnKeyDown` …（见 [08](./08-窗口输入与弹出层.md)） |
