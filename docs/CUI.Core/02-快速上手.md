# 02 · 快速上手

## 一、最小可运行程序

真实可运行的入口见 `Demo/main.cpp`。骨架如下：

```cpp
#include "CUI.h"            // 伞形头：一个 include 拿到全部能力
using namespace CUI;
using namespace CUI::DSL;   // CUI.h 已默认注入，可省略

int main() {
    Window window;

    auto label  = Text("Click count: 0").FontSize(24.0f)
                      .AlignHorizontal(Alignment::Center)
                      .ForegroundToken(ThemeTokenId::TextSecondary);

    auto button = ElevatedButton("Click Me!")
                      .Width(160.0f).Height(48.0f)
                      .AlignHorizontal(Alignment::Center)
                      .OnClick([label](UIElement*) mutable {
                          static int n = 0;
                          Borrow(label).Text("Click count: " + std::to_string(++n));
                      });

    auto root = Column(20, { label, button })     // 纵向 StackPanel，间距 20
                    .Align(Alignment::Center)
                    .Build();

    window.Fluent().Title("CUI Demo").Size(400, 300)
          .Root(root).Build().Show().Run();
    return 0;
}
```

链式出口的三条规则：

- `.Build()` → `std::shared_ptr<T>`（`const`，可重复调用，不释放所有权）
- 隐式转换 `operator std::shared_ptr<UIElement>()`
- `Borrow(ptr)` → 把已存在的元素重新拿回链式能力

## 二、窗口的两种建法

### A. `Window` + Fluent（推荐）

```cpp
Window w;
w.Fluent()
   .Title("我的窗口")              // UTF-8，内部转 UTF-16
   .Size(1280, 800)               // DIP
   .MinimumSize(800, 600)
   .Theme(ThemeMode::Dark)        // Dark / Light
   .Backdrop(BackdropType::Mica)
   .RenderStats(false)
   .Root(root)                    // 等价 w.SetRootElement(root)
   .Build()                       // 内部 Create()
   .Show()
   .Run();                        // 内部 RunMessageLoop()
```

底层签名：`bool Window::Create(const std::string& title, int w = 1280, int h = 800, bool transparentMode = false);`

### B. `CUIWindow`（自带标题栏的高层壳）

构造时已用 DSL 搭好 `StackPanel(TitleBar + contentContainer)`，你只管塞内容：

```cpp
CUIWindow app;                       // 默认 1200×750
app.Content(myRoot).Show().Run();     // 内部会先 ClearChildren()
```

## 四、事件怎么写

```cpp
// 1) DSL 便捷回调（控件专属，签名固定）
ElevatedButton("OK").OnClick([](UIElement* sender) { /* ... */ });
TextField("").OnTextChanged([](TextBox* box, const std::string& text) { /* ... */ });
SliderWidget().OnValueChanged([](Slider* s, float v) { /* ... */ });

// 2) 通用事件对象（Connect 返回 EventId，可 Disconnect）
EventId id = view->OnLinkClicked().Connect([](MarkdownView*, const std::string& href) { /* ... */ });
view->OnLinkClicked().Disconnect(id);

// 3) 回调属性（控件上预置的槽位）
elem->OnClick = [](UIElement* e) { /* ... */ };             // CallbackProperty 赋值
elem->OnClick.Connect([](UIElement* e) { /* ... */ });      // 多播

// 4) 重写虚函数（自定义控件里）
void OnMouseDown(Point pt) override;
bool OnKeyDown(int vkCode) override;                        // 返回 true = 完全消费
```

⚠️ DSL 的事件方法有**类型门槛**：`OnClick` 要求 `T` 派生自 `Control`；对 `TextBlock` / `Panel` 调用会**静默无效**（编译通过但不生效）。详见 [03](./03-DSL与控件速查.md)。

## 五、状态与绑定

```cpp
State<int> count{0};                       // core/State.h
count.Set(1);  int v = count.Get();

// 单向 / 双向绑定
label->Text.Bind(count, BindingMode::OneWay);
label->Text.Bind(textState, BindingMode::TwoWay);

// 派生值
auto text = MakeComputed<std::string>([](int c) { return std::to_string(c); }, count);
label->Text.Bind(text);

// 解绑
label->Text.Unbind();
```

`enum class BindingMode { OneWay, TwoWay, OneTime };`

绑定是**值语义**的：`Property<T>` → `PropertyRef<T,Id>` → 懒创建 `BindableProperty<T>`，随控件析构自动 `Unbind()`。

## 六、自定义控件骨架

```cpp
class Badge : public Control {
public:
    Badge() {
        Width  = 64.0f;                 // PropertyRef 赋值
        Height = 24.0f;
    }

    // 1) 自绘（唯一必须重写的绘制点）
    void OnRender(GraphicsContext& ctx) override {
        const Rect& b = GetBounds();                       // DIP
        if (!ctx.IntersectsPaintBounds(b)) return;         // 脏区裁剪，省开销
        auto& tm = ThemeManager::Instance();
        ctx.FillRoundedRect(b, 12.0f, tm.GetColor(ThemeTokenId::AccentColor));
        ctx.DrawText(m_text, b, tm.GetColor(ThemeTokenId::AccentForeground),
                     "微软雅黑", 12.0f,
                     DWRITE_TEXT_ALIGNMENT_CENTER, DWRITE_PARAGRAPH_ALIGNMENT_CENTER);
    }

    // 2) 想自己决定尺寸就重写（不重写则用 Width/Height + 基类逻辑）
    Size MeasureOverride(Size available) override { return Size(64.0f, 24.0f); }

    // 3) 内容变化 → 失效
    void SetText(const std::string& t) {
        m_text = t;
        InvalidateMeasure();          // 影响尺寸
        MarkRenderContentDirty();     // 影响外观
    }

private:
    std::string m_text;
};
```

`Control` 与 `UIElement` 的区别：`Control` 额外提供 Hover / Pressed / Focused 的过渡动画与视觉状态机。**纯展示元素**继承 `UIElement`，**可交互控件**继承 `Control`，**容器**继承 `Panel`。

## 七、加新文件时必须做的一件事

在 `CUI.Core.vcxproj` 的 ItemGroup 里手工加一行（用正斜杠或反斜杠均可）：

```xml
<ClCompile Include="ui\framework\controls\Badge.cpp" />
<ClInclude Include="ui\framework\controls\Badge.h" />
```

工程**没有通配符**。忘了加 `.cpp` → 链接期 `LNK2019: unresolved external symbol`。

## 八、新手最常见的 6 个报错

| 现象 | 原因 |
|---|---|
| `LNK2019` | 新 `.cpp` 没写进 vcxproj（见上） |
| 链式方法设了没效果 | 该方法是 `if constexpr (requires{...})` 静默降级，控件不支持 → 换控件专属方法或直接改属性 |
| 引用了临时 Builder 然后崩 | `ElementBuilder<X>& r = X().Width(1);` → 用 `auto b = ...;`（值） |
| 界面不刷新 | 改了数据没调 `InvalidateMeasure()` / `MarkRenderContentDirty()` |
| 鼠标坐标总差一点 | 用了物理像素；先 `ClientPhysicalToLogical()` 转 DIP |
| 中文字符串乱码 | 该工程配置缺 `/utf-8`（示例工程有漂移）；核心库本身已开 |
