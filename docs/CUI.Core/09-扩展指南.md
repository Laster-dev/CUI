# 09 · 扩展指南（加东西该改哪些文件）

> 每一步都标了**必须改的文件**。漏掉 vcxproj 或名字表是最常见的失败原因。

## 一、新增一个控件

| # | 做什么 | 改哪个文件 |
|---|---|---|
| 1 | 选基类：纯展示 → `UIElement`；可交互 → `Control`；容器 → `Panel`；图表 → `ChartBase` | 新建 `controls/MyWidget.h` |
| 2 | 成员属性用 `PropertyRef<T, PropertyId::Xxx>`（可绑定 + 自动失效） | 同头文件 |
| 3 | 重写 `void OnRender(GraphicsContext&)`；尺寸自定则重写 `MeasureOverride` / `ArrangeOverride` | 同头文件 + `MyWidget.cpp` |
| 4 | 属性 setter 里调 `InvalidateMeasure()` 或 `MarkRenderContentDirty()` | `MyWidget.cpp` |
| 5 | **把 `.cpp` 写进 `CUI.Core.vcxproj` 的 ClCompile** | `CUI.Core.vcxproj` |
| 6 | 加 DSL 工厂函数（可选但推荐） | `core/CUIDsl.h` 尾部（`inline ElementBuilder<MyWidget> MyWidgetWidget()`） |
| 7 | 加专属链式方法（可选） | `core/CUIDsl.h` 的 `ElementBuilder` 内，用 `if constexpr (requires { ... })` 写 |

### 骨架

```cpp
// controls/Badge.h
#pragma once
#include "Control.h"
#include "../core/Property.h"

namespace CUI {
class Badge : public Control {
public:
    Badge();

    void OnRender(GraphicsContext& ctx) override;   // 必须
    Size MeasureOverride(Size available) override;  // 尺寸自定时

    PropertyRef<std::string, PropertyId::Text> Text;   // 可绑定属性（示意）
};
}

// controls/Badge.cpp
#include "Badge.h"
#include "../render/GraphicsContext.h"
#include "../style/ThemeManager.h"
using namespace CUI;

Badge::Badge() { Width = 64.0f; Height = 24.0f; }

void Badge::OnRender(GraphicsContext& ctx) {
    const Rect& b = GetBounds();
    if (!ctx.IntersectsPaintBounds(b)) return;
    auto& tm = ThemeManager::Instance();
    ctx.FillRoundedRect(b, 12.0f, tm.GetColor(ThemeTokenId::AccentColor));
}

Size Badge::MeasureOverride(Size) { return Size(64.0f, 24.0f); }
```

### DSL 工厂写法

```cpp
inline ElementBuilder<Badge> BadgeWidget(const std::string& text = "") {
    auto b = ElementBuilder<Badge>();
    if (!text.empty()) b.Text(text);
    return b;
}
```

## 二、新增一个布局容器

1. 继承 `Panel`（`controls/Panel.h:11`），重写：

```cpp
Size MeasureOverride(Size availableSize) override;   // 必须对每个子节点 child->Measure(约束)
void ArrangeOverride(Rect finalRect) override;       // 必须对每个子节点 child->Arrange(矩形)
```

2. 在 `layout/Layout.h` / `layout/Layout.cpp` 的 `LayoutEngine` 分发函数里加分支（`MeasureElement` / `ArrangeElement` 按容器类型派发）。
3. 附加属性（如 `MyPanel.Left`）走 `PropertyId` 反射或强类型 `SetXxx/GetXxx`，并在 DSL 里暴露。
4. **vcxproj 加 `.cpp`**。
5. 加工厂函数 `MyPanelWidget()`。

## 三、新增一个属性

### A. 强类型（推荐）

- 在 `core/PropertyId.h` 的 `enum class PropertyId : uint16_t` **尾部**追加一项（⚠️ 只能尾部，别插中间，避免打乱既有编号/序列化）。
- 在 `core/PropertyId.cpp` 的名字表补上 `PropertyIdToName` / `PropertyIdFromName` 映射。
- 控件里声明 `PropertyRef<T, PropertyId::MyProp> MyProp;`（或 `Property<T>` 值语义版本）。
- 需要样式表/调试面板可见 → 在 `core/PropertyDesc.h` 补描述。

### B. 运行时反射值

`Value`（`core/Value.h:201`）底层是 `std::variant<monostate, bool, int, float, std::string, D2D1_COLOR_F, Thickness, void*>`。
**新增 variant 类型 = 改 `Value.h` 的声明 + `Value.cpp` 的所有转换分支**，成本较高，非必要不做。

## 四、新增主题 Token

1. `style/ThemeTokenId.h`：在 `enum class ThemeTokenId : uint16_t` 的 `Count` **之前**追加。
2. `style/ThemeTokenId.cpp`：补 `ThemeTokenIdToName` / `ThemeTokenIdFromName`。
3. `style/ThemeManager.cpp`：在 Light 与 Dark 两张色板里都填上颜色（漏一个 = 该主题下取到默认色）。
4. 控件用 `SetXxxToken(ThemeTokenId)` + `ThemeManager::GetColor()` 取色。

## 五、新增缓动曲线

1. `animation/AnimationService.h` 的 `enum class EasingType` 追加。
2. `animation/AnimationService.cpp` 的缓动计算 `switch` 里补分支。
3. 需要新参数 → 扩展 `AnimationSpec`（注意给默认值，别破坏既有调用）。

## 六、提交前检查清单

- [ ] 新 `.cpp` 已写进 `CUI.Core.vcxproj`
- [ ] 新增枚举只在**尾部**（或在 `Count` 之前）追加
- [ ] 名字映射表（`PropertyId` / `ThemeTokenId`）已同步
- [ ] `OnRender` 里有 `IntersectsPaintBounds` 早退
- [ ] 改数据后有 `InvalidateMeasure()` / `MarkRenderContentDirty()`
- [ ] Push/Pop（Clip、Opacity、Transform、Layer）成对
- [ ] 单位都是 DIP（除非 API 明确标注像素）
- [ ] 跨帧保存元素用 `weak_ptr`
- [ ] `ThemeMode::Light` 与 `Dark` 都验证过
- [ ] 若新增公开 API → 同步更新 `docs/CUI.Core/` 对应文档
