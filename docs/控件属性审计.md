# CUI 控件属性审计

对照范围：`PropertyGrid` 检查器 + `UIElement::SetProperty` / `GetProperty` + 各控件 `OnRender` / `Measure` 实际读取的字段。  
日期：2026-08-13。未改代码，只记录现状。

---

## 1. 根因（几乎每个控件都会踩）

检查器并不是按控件白名单出属性。流程是：

1. 把 **整张** `UIElement` `PropertyDesc` 表挂到目标上（含面板布局、Canvas/Grid/Dock、全部 Theme Token）。
2. 再叠各控件 `GetPropertyMetas()` 的 extras。
3. 未赋值的 Theme Token（`Unset`）会被滤掉；构造函数里 `SetXxxToken` 过的会显示。
4. 原始 RGB 色槽（`Background` / `Color` 等）被检查器隐藏，只留 Token。
5. 改值走 `PropertyGrid::ApplyTargetProperty`：少数控件有 `dynamic_cast` 特判，其余走 `PropertyDesc::set`，再不行走 `SetProperty`。

因此会出现三类「设了没反应」：

| 类型 | 表现 | 原因 |
|------|------|------|
| A. 基类噪音 | 检查器能改，视觉不变 | 属性属于 Panel/附加属性/未参与绘制 |
| B. 桥断裂 | 检查器有字段，读写都空操作 | extras 的名字不在 `PropertyId` 表 → `id = None`；或有 `PropertyId` 但没有 `PropertyDesc` / `SetProperty` / `ApplyTargetProperty` |
| C. 绘制忽略 | 存储改了，画的时候不用 | 自绘硬编码字号/圆角/边框，或只认 Token 不认 RGB |

`PropertyIdFromName` 只认识 `PropertyId.h` 里那一张表。extras 写成 `"header"`、`"lineSpacing"`、`"minTabWidth"` 这类名字时，检查器照样画出输入框，改值立刻 `return`。

## 2. 所有控件共用的无效项

下列挂在每个控件的检查器上，但对 **非对应容器 / 非对应父级** 无效。

### 面板布局（只对 Panel 子类有意义）

`Orientation`、`Gap`、`Align`、`ItemWidth`、`ItemHeight`、`LastChildFill`、`Rows`、`Columns`、`FlexGrow`

改 Button / Slider 的 Orientation 不会让它变成布局容器。Slider / RangeSlider / Splitter 自己读 `GetOrientation()`，这三项除外。

### 附加属性（只对特定父级有效）

- Canvas：`Canvas.Left/Top/Right/Bottom`
- Grid：`Grid.Column/Row/ColumnSpan/RowSpan`
- DockPanel：`DockPanel.Dock`

父级不是对应 Panel 时，设置被存下来，布局不用。

### RGB 色槽 API（检查器已藏，C++ API 仍在）

`Control::GetAnimatedBackground` **只认 Token**。`HoverBackgroundToken == Unset` 时 hover 回退到当前背景，**不会**用 `SetHoverBackground(RGB)`。`PressedBackground` 同理。

绝大多数自绘控件文字只读 `ColorToken`，`SetColor(RGB)` 无效。

### `Focused` 检查器开关

走 `OnFocus()` / `OnBlur()`，不经过窗口焦点管理。勾选后焦点环/输入态通常不对。

### 基类 Token 显示了也不画

控件构造里 `SetXxxToken` 后检查器会列出该项。若 `OnRender` 没 `GetXxxToken()`，改了只改存储。最典型：

- **Button / ToggleButton / SplitButton / DropDownButton**：构造里 `SetFocusedBorderToken`，绘制只用 `BorderToken`。
- 几乎所有非 Panel 控件：`DropdownBackgroundToken`、`GridLineBrushToken`、`ActiveTabBackgroundToken` 等与自身无关的 Token，只要被基类表带出来且曾赋值，就会出现。

## 3. 逐控件

图例：

- **无效**：检查器或 `SetProperty` 能改，绘制/行为不跟。
- **桥断**：检查器有字段，因 `PropertyId::None` 或没有 Set 特判，读写都空。
- **缺失**：控件已有 C++ API / 必要状态，检查器没有对应项（或挂错到别的 PropertyId）。

### 3.1 TextBlock

| | 项 |
|--|--|
| 有效 | Text、FontFamily、FontSize、FontWeight、Padding、ColorToken、Width/Height |
| 桥断 | `lineSpacing`、`lineHeight`（extras 名字不在 PropertyId 表） |
| 无效 | 面板布局、Canvas/Grid/Dock；BackgroundToken（`OnRender` 不铺底，只画字） |
| 缺失 | 无独立 `TextWrapping` / `TextAlignment` PropertyId（若以后要检查器可改，需补） |

### 3.2 Button / ToggleButton / SplitButton / DropDownButton

| | 项 |
|--|--|
| 有效 | Text、Icon、FontFamily、FontSize、Padding、CornerRadius、BorderThickness、Background/Hover/Pressed/Border/Color Token |
| 无效 | **FocusedBorderToken**（构造赋值，绘制不用）；FontWeight（绘制写死 `NORMAL`） |
| 缺失 | DropDown/Split：**Items**（有 `AddItem`，检查器无）；ToggleButton 的 IsOn 读写走特判，可用 |

### 3.3 HyperlinkButton

| | 项 |
|--|--|
| 有效 | Text、FontFamily、FontSize、Padding、ColorToken |
| 缺失 | **NavigateUri**（有 setter，无 PropertyId / metas） |
| 无效 | 面板布局等基类噪音；无独立 GetPropertyMetas |

### 3.4 CheckBox / RadioButton

| | 项 |
|--|--|
| 有效 | Text、FontFamily、FontSize、Padding、CornerRadius、BackgroundToken、CheckedBackgroundToken、ColorToken；CheckState（ApplyTargetProperty 特判，**写有效**） |
| 无效/读空 | CheckState **读**：无 `GetProperty` override，检查器当前值常空 |
| 桥断 | **IsThreeState**：有 PropertyId 和 metas，无 Set 特判、无 SetProperty override |
| 缺失 | RadioButton **GroupName**（extras `"groupName"` → None） |

### 3.5 ToggleSwitch

| | 项 |
|--|--|
| 有效 | IsOn（特判）；On/Off/Knob/Border/Color Token；不铺 Control 矩形底 |
| 桥断 | **Header**（`"header"` → None）。改检查器标题无效，必须 `SetHeader` |
| 无效 | Padding、CornerRadius、BackgroundToken（刻意跳过 `Control::OnRender`）；FontSize（标题字号硬编码） |

### 3.6 TextBox / PasswordBox

| | 项 |
|--|--|
| 有效 | Text、Placeholder、FontFamily、FontSize、FontWeight、Padding、CornerRadius、Background/Color/Placeholder/Caret/Underline Token |
| 桥断 | `lineSpacing`、`lineHeight`、`caretWidth`、`caretBlinkRate`、`TextWrapping`、`AcceptsReturn`（名字不在表或大小写不对） |
| 无效 | **IsReadOnly**：有 PropertyId 和 metas，ApplyTargetProperty **没有** TextBox 分支，SetProperty 也不处理 → 检查器改只读无效 |
| 缺失 | PasswordBox：`isPasswordRevealed`、`showRevealButton` → None；PasswordChar 无属性 |

C++ 侧 `SetIsReadOnly` / `SetTextWrapping` 等是好的，只是没接到检查器。

### 3.7 NumberBox

| | 项 |
|--|--|
| 有效 | ControlValue（特判 SetValue）；FocusedBorder/Border/Font 走内部 TextBox |
| 桥断/无效 | **Minimum / Maximum / Step**：检查器能改，无特判、无 SetProperty → 空操作 |
| 读空 | Value 当前值检查器常空（无 GetProperty override） |
| 缺失 | 表达式提交行为、Spinner 可见性 |

### 3.8 ComboBox / AutoSuggestBox / SegmentedControl

| | 项 |
|--|--|
| 有效 | Items（ComboBox / Segmented 有 SetProperty）；FontFamily/Size；Padding/CornerRadius/Border；FocusedBorder（这几个有读） |
| 缺失 | **SelectedIndex** / 当前选中项；AutoSuggest **Suggestions** 列表 |
| 无效 | ComboBox 的 ItemHeight extras 映射到基类 `ItemHeight`（UniformGrid 子项高），下拉行高是否跟它取决于实现，不要当成「下拉项高」专用 Id |

### 3.9 Slider / RangeSlider / RatingControl

| | 项 |
|--|--|
| 有效 | Orientation（Slider/Range）；Track/ActiveTrack/Thumb Token；RangeSlider 的 Lower/Upper/Min/Max/Step/MinRange（自己 override Get/Set） |
| 写有效读空 | Slider **Value**（特判 Set，无 Get override） |
| 无效 | Slider **Minimum / Maximum / Step**（metas 有，ApplyTargetProperty 只接了 Value） |
| 有效 | Rating：Value/Maximum/Step/IsReadOnly/IsClearEnabled（Get override + 特判 Set）；Fill/Track Token |
| 无效 | Slider/Rating 的 Padding（绘制不用）；Slider 的 Text |

### 3.10 ProgressBar / ProgressRing

| | 项 |
|--|--|
| 有效 | Value、IsIndeterminate（特判）；Fill/Track Token；CornerRadius（Bar） |
| 无效 | **Minimum / Maximum**（metas 有，无特判） |
| 读空 | Value / IsIndeterminate 检查器常空 |
| 无效 | Text、Font、Padding；Bar 高度很小时 BackgroundToken 几乎看不见 |

### 3.11 DatePicker / TimePicker / ColorPicker

| | 项 |
|--|--|
| 写有效读空 | DateStr / TimeStr / SelectedColor（特判 Set，无 Get override） |
| 有效 | 外观：Background/Border/Color Token、CornerRadius、Font（Date/Time 文本） |
| 缺失 | DatePicker：MinDate/MaxDate、日历是否打开；TimePicker：秒、24h；ColorPicker：Alpha、最近色 |

### 3.12 FilePicker / FolderPicker

| | 项 |
|--|--|
| 有效 | Text 当路径（特判 SetPath）；Placeholder、Font、Padding、CornerRadius、FocusedBorder |
| 缺失 | Filter、DialogTitle、是否允许多选 |

### 3.13 Image

| | 项 |
|--|--|
| 无效 | extras `"text"` 标成「源路径」，实际 `SetProperty(Text)` 改的是 `UIElement::m_text`，**不会** `SetSource` |
| 缺失 | Source、Stretch、ImageType、Icon（SVG 走 GetIcon，检查器当通用 Icon） |

### 3.14 ListBox / ListView / TreeView

| | 项 |
|--|--|
| 有效 | ListBox Items（SetProperty）；Font、Background/Selected/Hover/Border Token；TreeView Font、ItemHeight（基类字段）、缩进有 C++ setter |
| 桥断 | TreeView **indentWidth** extras → None |
| 缺失 | SelectedIndex、SelectionMode、列定义（ListView）、虚拟化数据源；ListView 无 Items metas |

### 3.15 TabView

| | 项 |
|--|--|
| 有效 | 已赋值的 Active/Inactive Tab、Underline、Header 背景 Token |
| 桥断 | **minTabWidth / maxTabWidth** extras → None（C++ `SetMinTabWidth` 有效，检查器无效） |
| 缺失 | SelectedIndex、标签列表、是否可关闭 |

### 3.16 PagingControl

| | 项 |
|--|--|
| 写有效读空 | CurrentPage、TotalPages（特判 Set） |
| 有效 | FontSize/Family、Hover/Pressed Token |
| 缺失 | 是否显示首页/末页、紧凑模式 |

### 3.17 InfoBar

| | 项 |
|--|--|
| 无效 | extras 把 **Text 当标题、Placeholder 当正文**。绘制用的是 `m_title` / `m_message`。检查器改 Text **不会** `SetTitle` |
| 缺失 | Title、Message、**Severity**、IsOpen、IsClosable、ActionText |

标题字号在绘制里写死 13px，改 FontSize 无效。

### 3.18 Expander

| | 项 |
|--|--|
| 桥断 | Header、Subtitle、IsExpanded、ExpandDirection 全部 extras 名字不在 PropertyId 表 |
| 有效 | Background/Hover/Pressed/Border/Color Token、CornerRadius |
| 缺失 | 对应 PropertyId + Get/SetProperty；内容子元素不能靠检查器设 |

### 3.19 Flyout / TeachingTip / Toast / MessageBox

| | 项 |
|--|--|
| Flyout | Padding/CornerRadius/Border 有效；缺失 Placement、是否打开 |
| TeachingTip | Title/Message Token 有效；缺失 Title、Message、ActionText、IsCloseVisible、Placement、MaxWidth（全无 metas） |
| Toast | extras：title/message/corner/durationMs/autoClose/closeable/offsetX/Y/spacing → **全部 None** |
| MessageBox | 对话框级 API，无检查器 extras |

### 3.20 MenuBar / ContextMenu / CommandBar / StatusBar / BreadcrumbBar

| | 项 |
|--|--|
| MenuBar | ColorToken 有效；无菜单项属性；不铺 Control 底 |
| CommandBar | 只有基类表；缺失 LabelPosition、Items、Overflow |
| StatusBar | Font 有效；缺失 Items 集合 |
| BreadcrumbBar | Font、Color/ActiveColor/Border Token 有效；缺失 Path |

### 3.21 NavigationView

| | 项 |
|--|--|
| 有效 | PaneBackground、Border、Color、SecondaryColor、Indicator Token |
| 损坏 | GetPropertyMetas 参数顺序写反：`{ "paneTitle", "string", "外观", "Pane Title" }` → displayName=`string`，type=`Pane Title`，id=None |
| 桥断 | paneTitle / header / openPaneLength / compactPaneLength 全部无效 |
| 缺失 | IsPaneOpen、PaneDisplayMode、SelectedItem、IsSettingsVisible、BackButton |

### 3.22 ScrollViewer / Splitter / Panel

| | 项 |
|--|--|
| ScrollViewer | Padding、ClipToBounds 有效；缺失 Horizontal/Vertical ScrollBarVisibility、滚动偏移 |
| Splitter | Orientation 有效；BackgroundToken 被拿去画分割线（语义是「线色」不是背景） |
| Panel 子类 | 面板布局属性在这里才是正主；子控件上那些项对 Panel 本身有效 |

### 3.23 LogView

| | 项 |
|--|--|
| 有效（但语义复用） | Text = **搜索过滤**；IsOn = **持久化**（自己 Get/SetProperty） |
| 无效 | FontSize/Padding（绘制硬编码行高 22、字号 12/11） |
| 缺失 | IsExpanded、FollowTail、MaxEntries、LevelMask；条目内容不是属性 |

### 3.24 MarkdownView

| | 项 |
|--|--|
| 有效 | Text → SetMarkdown（SetProperty override） |
| 桥断 | showLineNumbers → None |
| 部分有效 | CornerRadius/Border/Background/Color Token 画外框；正文样式大量硬编码 |

### 3.25 TerminalControl

| | 项 |
|--|--|
| 桥断 | extras `"shell"` → None |
| 部分 | fontSize/fontFamily 名字能对上基类 FontSize/FontFamily，是否同步到终端渲染器取决于 TerminalControl 是否在 SetFontSize 时转发给 buffer（基类 setter 只改 UIElement 字段） |
| 缺失 | 调色板、光标样式、滚动回溯行数 |

### 3.26 WindowTitleBar

无独立 metas。标题走 `SetTitle`，不是 `GetText()`。检查器改 Text 无效。

### 3.27 Chart（Bar / Line / Pie）

| | 项 |
|--|--|
| 有效 | ColorToken、TitleColorToken、Background（ChartBase 走 Control::OnRender） |
| 缺失 | Categories、Series、ShowGrid、ShowLegend、ShowTooltip |

### 3.28 ContextMenu 项 / NavigationViewItem

菜单项读 Font/Icon/Text。Item 级控件很少出现在 Showcase 检查器里。NavigationViewItem 跳过 Control 铺底。

## 4. 检查器 extras 名字对不上 PropertyId 的清单

这些字段会出现在检查器里，改了等于没改（`PropertyId::None`）：

| extras 名字 | 控件 |
|-------------|------|
| header / subtitle / isExpanded / expandDirection | Expander |
| header | ToggleSwitch、NavigationView |
| groupName | RadioButton |
| lineSpacing / lineHeight | TextBlock、TextBox |
| caretWidth / caretBlinkRate | TextBox |
| TextWrapping / AcceptsReturn | TextBox |
| isPasswordRevealed / showRevealButton | PasswordBox |
| showLineNumbers | MarkdownView |
| indentWidth | TreeView |
| minTabWidth / maxTabWidth | TabView |
| paneTitle / openPaneLength / compactPaneLength | NavigationView |
| title / message / corner / durationMs / autoClose / closeable / offsetX / offsetY / spacing | Toast |
| shell | TerminalControl |
| NavigateUri（连 extras 都没有） | HyperlinkButton |

有 PropertyId、检查器也列了、但 **Set 空操作**（无 desc、无特判、无 override）：

| PropertyId | 控件 |
|------------|------|
| IsThreeState | CheckBox |
| Minimum / Maximum / Step | Slider、ProgressBar、ProgressRing、NumberBox（Value 除外） |
| IsReadOnly | TextBox（Rating 有特判，可用） |
| Text（当路径/标题用） | Image Source、InfoBar Title —— 写到了错误的字段 |

有 PropertyId、**写有效、读常空**（缺 GetProperty override）：

Slider.Value、ProgressBar.Value/IsIndeterminate、NumberBox.Value、PagingControl 页码、DateStr、TimeStr、SelectedColor、CheckState。

## 5. 建议修的顺序

1. **停掉全量 PropertyDesc 挂载**：按控件白名单出检查器（布局只给 Panel，Token 只给该控件 `OnRender` 真正 `Get` 的那些）。
2. **补 PropertyId + PropertyDesc**（不要再靠 extras 字符串）：Header、IsExpanded、SelectedIndex、IsReadOnly、TextWrapping、NavigateUri、Source、Severity、MinTabWidth 等。
3. **控件自己 override Get/SetProperty**，少在 PropertyGrid 里堆 `dynamic_cast`。RangeSlider / LogView / RatingControl 是现成样板。
4. **Button 焦点边框**：绘制改读 `FocusedBorderToken`，或构造里不要 Set 一个画不到的 Token。
5. **InfoBar / Image**：extras 不要复用 Text；接到 `SetTitle` / `SetSource`。
6. **Control 底色**：要么让 RGB hover 生效，要么从 API 上删掉，避免 `SetHoverBackground` 看起来能用。
